# Ashfall Survivors updates

Signed game-content updates for the Ashfall Survivors Windows launcher.

## Connect your launcher

Paste this address into the launcher's update feed field and choose **SAVE FEED**, then **CHECK FOR UPDATES**:

```text
https://raw.githubusercontent.com/Keiaka/ashfall-updates/main/manifest.json
```

Choose **INSTALL UPDATE**, then **PLAY**. The launcher downloads and verifies game updates automatically when you install them; you do not need to extract another ZIP. The launcher itself must already be installed.

## Current release

This repository contains the public signed manifest and game packs only. Signing credentials must never be committed. Game-pack updates require the compatible Godot 4.3 / launcher 1 runtime. Engine or launcher upgrades may require a separate installer.
